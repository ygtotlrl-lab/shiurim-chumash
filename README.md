# שיעורים — סריקות חומש תורה תמימה

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו, והאפליקציה קוראת ממנו.

כל עמוד — תמונה מוכנה בתקן אחד: PNG שחור-לבן (1 ביט), ברוחב 1600 פיקסלים, קובץ לכל עמוד.

- `tt1/`–`tt5/` — חומש תורה תמימה, תיקייה לכל חומש (בראשית עד דברים), עמוד לכל קובץ (`1.png` ואילך).
- `tt2g/` — מקראות גדולות שמות (דפוס ראם, ניו יורק תרצ״ה, צילום וילנא): הפטרות תרומה עד פקודי, שחסרות בסריקת תורה תמימה (דפים רסח–רעב).
- `tt4g/` — מקראות גדולות במדבר (ירושלים תרצ״א), במספור ה-PDF: `278` (כא, יד–יח) ו-`280` (כא, יח–כג) — במקום הכפילים `tt4/270` ו-`tt4/272` שבסריקת תורה תמימה.
- `tt4s/` — הסריקות הכפולות של במדבר, מפוצלות לשני עמודיהן ובשם העמוד המודפס: `tt4/153` ⟵ `151` (עו) ו-`153` (עז) · `tt4/154` ⟵ `152` ו-`154` · `tt4/237` ⟵ `237` (קיט) ו-`239` (קכ) · `tt4/238` ⟵ `238` ו-`240`. העמוד התחתון בכל כפולה קטוע בתחתיתו כבר בסריקת המקור.
- `hft/` — הפטרות מכל השנה, דיהרנפורט תקנ״ג: הפטרות החגים והתעניות, העמודים חתוכים לגבולות הטקסט.
- `mnh/` — ספר המנהגים (מנהגי חב״ד), עמ׳ 82–83: «סדר ההפטרות שיש בהם חלוקי מנהגים».

מאגר נפרד מהאפליקציה — האתר מוגבל ל-1GB, והסריקות שוקלות את רובו.

שמות התיקיות: התיקייה הראשית — קוד הספר, 2–4 אותיות לטיניות משמו העברי, ובספר רב־כרכים הקוד ומספר הכרך; השלמה מדפוס אחר — תיקייה משלה: קוד התיקייה שהיא משלימה ואות המקור (`g` מקראות גדולות · `v` ויניציאה · `x` עותק אחר של אותו דפוס · `l` וילנא · `t` תר״ס · `s` סריקה כפולה שפוצלה לשני עמודיה המודפסים); שם הקובץ — מספר העמוד בסריקת המקור.
